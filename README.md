# Everyday AI for seniors

Phone-first Chinese and English course guide.

Published site: https://dannyngweekiat.github.io/kajang-senior-ai/

Plain HTML, CSS and JavaScript. GitHub Pages publishes the main branch from the repository root. No build, backend or API key is needed.

Edit the website files and push to main to update the site. Keep relative asset links so the guide works under this project URL.

ChatGPT is the main teaching tool; the video activity uses Google Flow in a phone browser. AI availability and free usage limits vary. Some demonstrations reuse the same verified app controls. The hawker ten-second generation submission recording remains pending because the capture account had no Flow credits; its existing generated output and other demonstrations are included.

## Search and sharing

Chinese and English have separate crawlable URLs, with reciprocal language alternatives, canonical links, course structured data and static lesson text before JavaScript enhancement. The step reader and legacy hash links remain supported. Favicons, Apple touch icons and language-specific 1200 x 630 sharing images are included. sitemap.xml lists the 20 public pages.

Submit the sitemap in Google Search Console after verifying the URL-prefix property for this project site. Search-engine indexing and social-network preview caches are external. A project-folder robots.txt would not control crawlers on github.io; that file must live at the domain root, so no misleading project robots.txt is included. No analytics, tracking or fabricated verification tags are added.
