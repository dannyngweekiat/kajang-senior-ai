Ask about a photo

Choose a practice photo and ask ChatGPT about it.

  1. Choose a photo

    Choose a clear menu or object photo without private details.

  2. Tap plus

    Tap the highlighted plus to add a photo.

  3. Choose Photos

    Open Photos and choose one picture.

  4. Try asking this

    Copy this text, then paste it into ChatGPT’s message box.

    Describe the main object in this photo in simple Chinese. Mention only what is clearly visible. Tell me when uncertain rather than guessing.

  5. Check the photo

    Check that you selected the right picture.

  6. Send the photo and question

    Tap the circled send arrow.

  7. Ask a follow-up

    Copy this text and send it in the same ChatGPT chat.

    What is this object usually used for? Tell me if the photo is not enough to identify it.

  8. Compare with the object

    Compare the reply with the object. Do not ask it to guess from a blurry photo; compare clear and blurry examples in class. Keep faces and private details out.

Five more things to try

  • Read a package label

    Photograph storage instructions on a package, ask for an explanation and compare it with the label.

  • Identify a plant

    Photograph a plant, ask what it might be and check the suggestion.

  • Translate a sign

    Photograph a sign without private details and ask for a translation.

  • Read everyday instructions

    Photograph instructions on an everyday product. Ask for a few simple steps, then check them against the packaging.

  • Turn a list into text

    Photograph a shopping list without private details. Ask for a typed version and check the items and quantities.
